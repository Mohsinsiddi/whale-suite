How to Generate These Images

  1. Open this file in Chrome at file:///path/to/public/og-preview.html
  2. Use Chrome DevTools (F12) > More Tools > "Capture node screenshot"
  3. Right-click on each .og-image container and capture at exact size
  4. For the scaled Twitter image, capture at full 1200x1200 (it's shown at 50% scale)
  5. Save files to /public/ folder with these names:
  • og-image.png (1200x630)
  • og-image-square.png (1200x1200)
  • og-image-small.png (600x315)
  • apple-touch-icon.png (180x180)
  • icon-192.png (192x192)
  • icon-512.png (512x512)

Tip: Use an online tool like realfavicongenerator.net to generate all favicon sizes from the SVG, or use the SVG directly (modern browsers support it).
